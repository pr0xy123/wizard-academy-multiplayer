# Character Animations

Place your KayKit Character Animations here.

## Required Files

This folder should contain animation GLTF files:
- `Idle.gltf` - Standing still animation
- `Walking.gltf` - Walking animation  
- `Running.gltf` - Running animation
- `Jump.gltf` - Jumping animation
- `Attack.gltf` - Attack animation
- `Death.gltf` - Death animation

## Download From:
https://kaylousberg.itch.io/kaykit-character-animations

## Instructions:

1. Download the KayKit Character Animations pack (FREE)
2. Extract the downloaded ZIP file
3. Navigate to the animations folder
4. Copy all `.gltf` animation files to this directory

The game will automatically blend animations based on player actions:
- **Idle**: When standing still
- **Walking**: When moving with WASD/arrows
- **Running**: When holding Shift while moving
- **Attack**: During combat encounters
- **Jump**: When spacebar is pressed (if implemented)

Note: Animation files from the KayKit pack are already compatible with the character models!
