# Environment Assets

Place your KayKit Dungeon Remastered assets here.

## Required Files

### Props (public/models/environment/props/)
Common dungeon items like:
- `chest.gltf` - Treasure chests
- `barrel.gltf` - Barrels
- `crate.gltf` - Crates
- `torch.gltf` - Wall torches
- `table.gltf` - Tables
- `chair.gltf` - Chairs
- And more!

### Dungeon Pieces (public/models/environment/dungeon/)
Modular dungeon components:
- Wall pieces
- Floor tiles
- Doors
- Stairs
- Columns
- And more!

## Download From:
https://kaylousberg.itch.io/kaykit-dungeon-remastered

## Instructions:

1. Download the KayKit Dungeon Remastered pack (FREE version - 200+ assets!)
2. Extract the downloaded ZIP file
3. Navigate to the appropriate folder (GLTF format recommended)
4. Copy prop files to the `props/` folder
5. Copy dungeon structure files to the `dungeon/` folder

## Current Integration:

The game is set up to load:
- **Chests**: Will replace geometric chest models
- **Barrels & Crates**: Can be placed as decorative props
- **Torches**: Can replace point lights with 3D models
- **Walls & Floors**: Can replace the basic geometric dungeon
