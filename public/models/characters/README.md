# Character Models

Place your KayKit Adventurers character models here.

## Required Files

Each character folder should contain:
- `[CharacterName].gltf` - The model file
- `[CharacterName].bin` - The binary data file (if separate)

## Download From:
https://kaylousberg.itch.io/kaykit-adventurers

## Expected File Structure:

```
characters/
├── warrior/
│   ├── Knight.gltf
│   └── Knight.bin (if applicable)
├── mage/
│   ├── Mage.gltf
│   └── Mage.bin (if applicable)
├── rogue/
│   ├── Rogue.gltf
│   └── Rogue.bin (if applicable)
└── ranger/
    ├── Ranger.gltf
    └── Ranger.bin (if applicable)
```

## Instructions:

1. Download the KayKit Adventurers pack (FREE version)
2. Extract the downloaded ZIP file
3. Navigate to the `Characters_gltf/` folder
4. Copy the appropriate character files to each subdirectory:
   - Knight → warrior/
   - Mage → mage/
   - Rogue → rogue/
   - Ranger → ranger/

5. Make sure both `.gltf` and `.bin` files are in the same directory

The game will automatically detect and load these models when you select a character class!
